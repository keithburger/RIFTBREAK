# RIFTBREAK

A top-down, survivor-style action roguelite for the browser. Move, dash, and draft a build from
40 weapons, 80 evolutions, 20 fusions and 45 elemental reactions across four biomes and eight bosses.

```bash
npm ci
npm run dev        # develop
npm run build      # static production build in dist/ (no backend, no CDN)
npm run preview    # serve dist/ on :4173
```

**Controls:** WASD / arrows move · Space dashes · Esc pauses · 1–3 pick upgrades.
Touch: drag anywhere to move, DASH button bottom-right. Gamepad: left stick + A.
